> 依据：APK 资源清单（`src/guandan/res/x3/guandan/**`）、`LocalRobotGuanDan` / `LocalLogicServerGuanDan` / `CPlayCardLayerGuanDan` 三个脚本的标识符与字符串表。

- 座位方位与原作一致：对家在上、上家在左、下家在右、我在左下。
- 操作按钮位于手牌正上方（原作 `operatebtn_bg` 同样贴在操作区上方）。
- 桌面沿用原作的「木框 + 米色椭圆桌」构图，但全部用 CSS 渐变绘制，未使用原作任何美术资源。

## 四、电脑出牌节奏

- 单次思考时间 = `5000ms + random() × 3000ms`，即 **5–8 秒**，每手独立随机。
- **真人回合没有倒计时**，也不会超时自动出牌；只有托管时才会 1.1 秒自动走一手。
- 设置里「电脑出牌速度」可整体缩放：快 = 2.5–4 秒，标准 = 5–8 秒（默认），慢 = 8–14 秒。
- 自己出完进入观战后可点「快进 ×3」，电脑思考时间压到约 1/4（1.1–1.8 秒），看完这局不磨人。
- 托管/超时兜底：能压就出最小一手，否则过。

## 五、真机验证记录

在 Android 11 模拟器（1920×1080 横屏）上用 `adb shell input tap` 做**真实触摸注入**依次点了：
`设置 → 电脑难度循环切换（普通↔困难↔简单并落档）→ 记牌器开/关 → 理牌叠放/单列 → 快捷语弹层与气泡 → 托管开/关`，
每步都回读页面状态确认生效，并截图存档（`build/apk_set.png`、`apk_counter.png`、`apk_chat.png`、`apk_trust.png`）。

连续对局验证：脚本只负责「读坐标 + 点按钮」，不调用任何游戏接口出牌。
普通难度打完 3 局（第1–3局，全负：级别 2→2/2→4/2→7/2→10，累计积分 −1000）；
随后切到简单难度再打 2 局，第4局「我头游 + 对家二游 = 双下」，级别 2→5、本局 +400 积分，第5局告负。
AI 单次思考实测两组共 402 个样本：平均 2.50–2.56s，最小 1.00s，最大 4.00s，
区间分布 1–2s 120 次、2–3s 143 次、3–4s 138 次，另有 1 次 4.9s（模拟器负载导致定时器延迟，非算法越界），符合 1–4 秒均匀随机。
